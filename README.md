# Python Taco Order System

A text-based taco ordering system created in Python.

## Overview

This program allows users to browse a taco menu, select items, manage their cart, and calculate their order.

## Technologies

* Python
* Dictionaries
* Functions
* Loops
* Conditional statements
* User input

##  Features

* Displays a menu of taco options
* Allows users to select items
* Manages a shopping cart
* Calculates order totals
* Uses input validation

##  Future Improvements

* Add a graphical user interface
* Add more menu items
* Add quantity selection
* Add order history
* Add payment functionality
